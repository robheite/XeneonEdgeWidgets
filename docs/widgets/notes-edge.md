# Notes Edge

Notes Edge is a self-contained persistent checklist and notes widget for
XENEON EDGE. It does not require Edge Companion.

## Features

- create, edit, complete, and archive notes;
- optional due dates and times;
- permanently clear archived notes after confirmation;
- maintain multiple locally saved lists;
- reconnect replacement widget instances to an existing named list; and
- optionally hide the list name.

## Requirements

- Windows 10 or 11
- CORSAIR iCUE 5.48 or later

## Install

Follow [Installing widgets](../installing-widgets.md) and import
`notes-edge.icuewidget`.

## Settings

- List name
- Show list name

## Storage

Lists are stored in the widget browser profile using local storage. Multiple
Notes Edge instances can share a named list, and each widget remembers its
selected list. Removing or replacing a page widget does not intentionally
delete the saved lists, but clearing iCUE's widget browser data can remove
them.

Notes remain on the current Windows installation and are not synchronized to a
cloud service.
