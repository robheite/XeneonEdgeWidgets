Edge Companion for XENEON EDGE Widgets

Run EdgeCompanion-Setup-<version>.exe to install the companion for your Windows
account. Administrator access and a separate .NET runtime are not required.

The installer registers edgecompanion:// so installed widgets can start the
companion when it is offline. Windows may show a SmartScreen warning because
the initial public installer is not code-signed.

Documentation:
https://github.com/robheite/XeneonEdgeWidgets/blob/main/docs/companion.md
